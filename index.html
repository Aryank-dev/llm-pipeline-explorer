2. Transformer Self-Attention Visualizer

Real-time scaled dot-product attention weights across active sequence tokens.
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

Each token computes its Query vector $Q$ against all Key vectors $K$. The softmax normalizes dot products into a probability distribution summing to 1.0.

5. Pairwise Cosine Similarity Matrix & Angular Distance

Mathematical dot products and angular displacement across all corpus sentence vectors.
$$\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}, \quad \theta = \arccos(\text{sim})$$
Why cosine similarity matters in transformers
In modern LLMs, cosine similarity provides length-invariant semantic direction. Regardless of prompt length, normalized dot products measure true directional alignment.
