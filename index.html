2. Transformer Self-Attention Visualizer

Real-time scaled dot-product attention weights calculated across active tokens.
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

Each token calculates its Query vector $Q$ against all other tokens' Key vectors $K$. The softmax normalizes dot products into a probability distribution summing to $1.0$ ($100\%$).

4. Latent Vector Arithmetic ("Word Algebra")

Perform linear algebraic operations in 64-D embedding space and project the resultant vector back into 3D.
$$\mathbf{v}_{\text{result}} = \frac{\mathbf{v}_A - \mathbf{v}_B + \mathbf{v}_C}{\|\mathbf{v}_A - \mathbf{v}_B + \mathbf{v}_C\|_2}$$

Arithmetic Prediction Output

Select vectors and click Compute to predict the nearest semantic neighbor in latent space.

5. Pairwise Cosine Similarity Matrix & Angular Distance

Mathematical dot products and angular displacement between all corpus sentence vectors.
$$\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}, \quad \theta = \arccos(\text{sim})$$
Why Cosine Similarity Matters in Transformers
In modern LLMs, cosine similarity provides length-invariant semantic direction. Whether a prompt is brief or elaborate, dot products capture semantic alignment!
